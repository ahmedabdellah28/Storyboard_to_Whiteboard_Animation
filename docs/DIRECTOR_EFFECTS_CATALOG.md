# كتالوج تأثيرات الموشن جرافيك الموحد (Director Effects Catalog)

أصبح بإمكانك الآن إضافة أي تأثير لأي عنصر في أي سيكشن مباشرة وبمنتهى السهولة داخل ملف `manifest.json` بمجرد كتابة اسمه، دون الحاجة لأي برمجة إضافية.

---

## 1. حركات الدخول (Entrances)
تُكتب في خانة `"entrance"` داخل العنصر:

| اسم التأثير في المانيفست | الوصف بالعربي | مثال الاستخدام |
| :--- | :--- | :--- |
| `"pop_bounce"` | ظهور انطلاقي مع ارتداد مرن وتخامد فيزيائي طبيعي | `"entrance": "pop_bounce"` |
| `"squash_drop"` | سقوط حر بالجاذبية من الأعلى مع انضغاط ومطاطية | `"entrance": "squash_drop"` |
| `"slide_in"` | انزلاق خاطف من جانب الشاشة مع تمويه حركي سريع | `"entrance": "slide_in"` |
| `"zoom_in"` | تقريب ناعم من العمق مع تدرج الشفافية | `"entrance": "zoom_in"` |

---

## 2. الحركات المستمرة والتنقلات (Idle & Movement)
تُكتب في خانة `"idle"` لمنع جمود العنصر أثناء حديث الراوي:

| اسم التأثير في المانيفست | الوصف بالعربي | مثال الاستخدام |
| :--- | :--- | :--- |
| `"floating"` | طفو عضوي ناعم ومستمر للأعلى والأسفل (تنفس فيزيائي) | `"idle": "floating"` |
| `"orbit_arc"` | انتقال قوسي منحنٍ عبر الشاشة مع ميلان طبيعي | `"idle": "orbit_arc"` |

---

## 3. حركات الخروج (Exits)
تُكتب في خانة `"exit"` لإخفاء العنصر عند نهاية توقيته:

| اسم التأثير في المانيفست | الوصف بالعربي | مثال الاستخدام |
| :--- | :--- | :--- |
| `"shrink_out"` | انكماش نابض سريع وتلاشٍ رشيق في الشفافية | `"exit": "shrink_out"` |
| `"slide_out"` | انزلاق خاطف باتجاه حواف الكادر مع تمويه حركي | `"exit": "slide_out"` |
| `"fly_away"` | تحليق صاعد متسارع للأعلى خارج الشاشة | `"exit": "fly_away"` |
| `"fade_out"` | تلاشٍ تدريجي هادئ للشفافية | `"exit": "fade_out"` |

---

## 4. تأثيرات الوميض والجاذبية البصرية (Visual & Color Effects)
تُكتب داخل قائمة `"effects"` في أي ثانية محددة:

```json
"effects": [
  { "type": "tint_flash", "time": 12.5, "color": "cyan" },
  { "type": "white_strobe", "time": 18.2 },
  { "type": "wiggle", "time": 24.0 },
  { "type": "light_sweep", "time": 15.0 },
  { "type": "neon_glow", "color": "gold" }
]
```

* **`"tint_flash"` (الوميض اللوني النيون):**
  * يدعم الألوان: `"cyan"`, `"gold"`, `"red"`, `"emerald"`, `"purple"`, `"white"`.
* **`"white_strobe"` (الوميض الضوئي الساطع):**
  * فلاش أبيض خاطف وشديد النقاء للحظات الصدمة والاكتشاف.
* **`"wiggle"` (هزة الانتباه الكرتونية):**
  * اهتزاز مائل لفت انتباه المشاهد لعنصر محدد.
* **`"light_sweep"` (المسح الضوئي النيون):**
  * بريق شعاع مسح يمر عبر تفاصيل العنصر.
* **`"neon_glow"` (توهج هالة النيون):**
  * إشعاع نيون ملون محيط بالعنصر.

---

## 5. وميض حواف الكاميرا المستطيلة (Camera Edge Border Flash)
تُكتب على مستوى المشهد `"camera_effects"` لتعطي وميض خطر أو تنبيه محيطي على إطار الكاميرا:

```json
"camera_effects": [
  {
    "type": "border_flash",
    "time": 51.5,
    "color": "red",
    "opacity": 45.0,
    "pulses": 2
  }
]
```
* **الألوان المدعومة:** `"red"` (خطر / لعنة)، `"cyan"` (طاقة عصبية / نشاط ذهني).
* **الشكل:** إطار مستطيل ناعم وخفيف 16:9 يحيط بأبعاد الشاشة دون تغطية المحتوى.
