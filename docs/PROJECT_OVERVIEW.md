# 📷 ➜ ▶️ نظرة عامة على المشروع — Storyboard to Whiteboard Animation

## 🎯 الهدف

تطبيق مفتوح المصدر يعمل **بدون اتصال بالإنترنت** لتحويل الصور الثابتة (Storyboards / رسومات / لوحات تعليمية) إلى فيديوهات أنيميشن بأسلوب **الرسم على السبورة البيضاء (Whiteboard Drawing Animation)** — يشبه فيديوهات YouTube التعليمية حيث تظهر يد ترسم المحتوى تدريجياً.

## 🎬 المحركات الرئيسية

### 1. Concentric Orbital Engine (المحرك المداري)
- يرسم العناصر باستخدام مسارات مدارية متحدة المركز (360°)
- لا يترك أي فجوات في الرسم
- مثالي للأشكال والرسومات الهندسية

### 2. Deep Pipeline Engine (المحرك العميق)
- محرك سينمائي متقدم يجمع بين:
  - **كاميرا سينمائية**: تكبير، إمالة، انتقال سلس بين اللوحات
  - **محرك خط عربي RTL**: كتابة يدوية سطر بسطر
  - **رسم تدريجي**: كشف البكسلات تحت القلم فقط
  - **مؤثرات بصرية**: Parallax، Banking Tilt، Intro/Outro

### 3. V3 Renderer (المصيّر)
- يضمن **صفر تسرب مسبق** للبكسلات (لا يظهر شيء قبل رسمه)
- يحافظ على **100% من جودة الصورة الأصلية** (MAE=0, MSE=0)
- يد رسم متزامنة مع مسار القلم بدقة Subpixel
